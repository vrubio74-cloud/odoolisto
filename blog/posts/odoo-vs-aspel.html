¿Qué es Aspel y para quién está pensado?

What is Aspel and who is it for?

Aspel es un conjunto de programas mexicanos vendidos como productos separados: Aspel SAE (ventas, inventario y cuentas por cobrar), Aspel COI (contabilidad), Aspel NOI (nómina), Aspel BANCO (conciliación bancaria) y Aspel CAJA (punto de venta). Cada uno se instala y se factura de forma independiente. Nació como software de escritorio para PC o red local (LAN), y aunque ya existen planes de suscripción con acceso remoto limitado, su lógica sigue siendo la de módulos aislados que hay que hacer hablar entre sí.

Aspel is a set of Mexican programs sold as separate products: Aspel SAE (sales, inventory and accounts receivable), Aspel COI (accounting), Aspel NOI (payroll), Aspel BANCO (bank reconciliation) and Aspel CAJA (point of sale). Each one is installed and billed independently. It started as desktop software for a PC or local network (LAN), and although subscription plans with limited remote access now exist, its logic is still separate modules that need to be made to talk to each other.
